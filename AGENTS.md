# Sleep Timer

Ürün kararları için `.agents/skills/stream-sleep-timer/SKILL.md` dosyasını kullan.
Eklentinin çalışma zamanına harici bağımlılık veya uzaktan çalıştırılan kod ekleme.
Kişisel Netflix HTML dökümünü depoya dahil etme; testlerde sadeleştirilmiş fixture kullan.
Davranış değişikliklerinde `npm test` çalıştır. DOM simülasyonu sonuçlarını gerçek Netflix testi olarak raporlama.
Dağıtım paketini `npm run package` ile üret; `node_modules` eklenti paketine girmez.
